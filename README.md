# Prostudio

موقع الاستوديو بشكل بروفايل انستغرام، مع هايلايتات تفتح مثل الستوري.

## تشغيله
افتح `index.html` بالمتصفح، ما يحتاج أي تنصيب.

## تبديل المحتوى
كل المحتوى بملف واحد: `assets/js/data.js`
- **الهايلايتات**: الاسم، الغلاف، والستوريات (صورة `image`، فيديو `video`، أو نص مؤقت `text`)
- **المنشورات**: صور شبكة الأعمال
- **الروابط**: رقم الواتساب ويوزر الانستغرام

حط الصور والفيديوهات داخل `assets/highlights/<اسم-الهايلايت>/` واكتب مسارها بالملف.

## التحكم بالستوري
- ضغطة على اليسار تروح للتالي، وعلى اليمين ترجع للسابق
- تعليك بالإصبع يوقف الستوري
- سحب لجوه يسكّر، وسحب يمين أو يسار ينقلك للهايلايت اللي بعده
- بالكيبورد: الأسهم، Space للإيقاف، Esc للإغلاق
