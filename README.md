# ProStudio — مونتاج وتصوير الفيديوهات الطبية

موقع تعريفي لخدمات **مصطفى** في مونتاج الفيديوهات الطبية وفريق التصوير الميداني.

- للتواصل: 07738223911 (اتصال / واتساب)
- موقع ثابت (HTML/CSS/JS) بدون أي تبعيات — افتح `index.html` مباشرة أو ارفعه على GitHub Pages.

## مشهد ثلاثي الأبعاد
الواجهة استوديو 3D يتحرك مع التمرير (Three.js محفوظة داخل `vendor/`): كاميرا سينمائية على ترايبود تصوّر مجسّم DNA، إضاءة سوفت بوكس، صناديق معدات، وحاسبة مونتاج تعرض بث الكاميرا المباشر داخل واجهة برنامج المونتاج.

## الملفات
- `scene.js` — بناء المشهد ثلاثي الأبعاد وحركة الكاميرا مع التمرير
- `index.html` — محتوى الصفحة (عربي، RTL)
- `styles.css` — التصميم والتجاوب مع الموبايل
- `script.js` — القائمة، فلترة الأعمال، ونموذج الطلب الذي يرسل إلى واتساب
