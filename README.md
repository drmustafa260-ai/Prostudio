# بروستوديو للعيادات (Prostudio Clinics)

نظام ويب عربي (RTL) لإدارة العيادات: المرضى، الأطباء، والمواعيد.

## المزايا الحالية
- **لوحة التحكم**: مواعيد اليوم، عدد المرضى والأطباء، إيراد الشهر من الزيارات المكتملة.
- **المرضى**: إضافة، بحث بالاسم أو الهاتف، ملف المريض مع الملاحظات الطبية وسجل المواعيد.
- **الأطباء**: إضافة وحذف مع التخصص.
- **المواعيد**: حجز، عرض حسب اليوم والطبيب، تغيير الحالة (مجدول / مكتمل / ملغي).

## التقنيات
Next.js 15 (App Router + Server Actions) · TypeScript · Tailwind CSS · Prisma + SQLite

## التشغيل
```bash
npm install
cp .env.example .env
npm run setup     # ينشئ قاعدة البيانات ويضيف بيانات تجريبية
npm run dev       # http://localhost:3000
```

للانتقال إلى PostgreSQL لاحقاً: غيّر `provider` في `prisma/schema.prisma` و`DATABASE_URL` في `.env`.

## الخطوات القادمة المقترحة
- تسجيل الدخول والصلاحيات (مدير / طبيب / استقبال)
- الفواتير والمدفوعات وطباعة الإيصالات
- الوصفات الطبية والتشخيص لكل زيارة
- تذكير المرضى بالمواعيد عبر واتساب/SMS
- تقارير شهرية
